What is counted Regular pack_untilize BH fast_untilize Why it matters
Unpack LLK calls 4 calls to llk_unpack_A, one per tile. 1 call to llk_unpack_fast_untilize_block for unit_dim=4. Fast reduces per-tile unpack-call overhead for the common non-BFP path.
Real UNPACR reads 16: four faces per tile times four tiles. 16: same face data must be read. This is not the main fast-path win; both paths move the same input payload.
Zero SrcB dvalid sideband 24 traced generic UNPACR_NOP dvalids. 0 for 16-bit DEST; 16 only for native fp32 DEST. Fast avoids generic zero-SrcB sideband traffic when math can copy SrcA directly with MOVA2D.
Pack MOP runs 2: top strip, then bottom strip. 2: top strip, then bottom strip. The phase count is the same, so the animation has the same two pack phases.
PACR instructions 128: 16 rows x 4 tiles x 2 phases. 64: 16 rows x 2 PACRs x 2 phases. Fast halves pack-side PACR count for a full 4-tile chunk.
Full PACR read width 2 interfaces (read_intf_sel=3), one 32-datum row fragment. 4 interfaces (read_intf_sel=0), one 64-datum row fragment. Math writes a DEST layout that lets pack read wider row-major strips.
Assumptions: four-face tiles, full_ct_dim=4, unit_dim=4, non-BFP input, and 16-bit DEST copy. Compressed BFP keeps per-tile addressing on unpack; native fp32 DEST keeps the zero-SrcB dvalid sideband. The animation steps are dataflow phases, not one instruction per step; both paths have top and bottom pack phases, but the trace shows 128 regular PACRs versus 64 fast PACRs inside those phases. Implementation Notes

Regular path

pack_untilize_block loops over input tiles, unpacks each tile, copies each tile into a standard DEST slot, then llk_pack_untilize emits row-major output with two active packer interfaces for 4-face tiles. For the shown 4-tile row, the packer performs 64 top-strip PACRs and 64 bottom-strip PACRs.

Fast path

fast_untilize_block works in 2/3/4-tile units. Math writes a custom DEST layout so pack can use STRIDED_MODE and four active interfaces for full-width PACRs. For the shown 4-tile row, the packer performs 32 top-strip PACRs and 32 bottom-strip PACRs.

Trace basis

Counts are trace-checked against current ttsim and then tied back to the LLK source: llk_unpack_A.h, llk_pack_untilize.h, llk_unpack_fast_untilize.h, and llk_pack_fast_untilize.h.

Wider rows

Rows wider than four tiles repeat the same unit flow. The strided pack variant closes each chunk row and advances output L1 by one full row stride. The direct small-CT path avoids materializing decomposition state.
